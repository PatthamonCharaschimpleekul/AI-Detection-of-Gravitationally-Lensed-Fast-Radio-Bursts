# Track C · source timing

**Purpose:** Likelihood for a shared delay and flux ratio across a source's burst pairs, weighted by pair scores; background from time-scrambled burst lists.

**Inputs:** Burst arrival times, fluences, pair scores, exposure.

**Outputs:** Source-level scores.

Diagram box in [pipeline.mmd](/pipeline.mmd). Large files go in `data/` or `outputs/` inside this folder (gitignored).
