# Phase 1 · Semi-synthetic lensed repeaters

**Purpose:** Real repeater bursts, real noise and real exposure; simulate only the lensing (Project_Description.md Sec. 5, Phase 1).

**Inputs:** CHIME/FRB Catalog 2 dynamic spectra, table and exposure; FAST/Blinkverse for augmentation.

**Outputs:** Lensed and unlensed repeater burst lists ready for injection.

Diagram box in [pipeline.mmd](/pipeline.mmd). Large files go in `data/` or `outputs/` inside this folder (gitignored).
