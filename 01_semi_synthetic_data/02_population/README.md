# Population stats

**Purpose:** Burst rate, DM, fluence, width and repeater statistics from the Catalog 2 table; z from DM via the Macquart relation.

**Inputs:** Catalog 2 table.

**Outputs:** Per-repeater parameters and redshift samples.

Diagram box in [pipeline.mmd](/pipeline.mmd). Large files go in `data/` or `outputs/` inside this folder (gitignored).
