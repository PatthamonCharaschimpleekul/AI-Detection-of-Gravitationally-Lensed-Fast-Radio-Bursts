# Lens simulator

**Purpose:** Galaxy lenses (SIS/SIE, Δt days–months) and compact lenses (point mass, Δt µs–ms).

**Inputs:** Population parameters.

**Outputs:** Per-event Δt, magnifications, image count.

Diagram box in [pipeline.mmd](/pipeline.mmd). Large files go in `data/` or `outputs/` inside this folder (gitignored).
