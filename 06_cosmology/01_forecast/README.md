# Yield forecast

**Purpose:** N_exp for Catalog 2 (computed before unblinding) and forecasts for CHIME as observed, a longer CHIME-like survey and a BURSTT-like all-sky monitor.

**Inputs:** ε maps, exposure, lens population.

**Outputs:** Expected numbers of lensed repeaters.

Diagram box in [pipeline.mmd](/pipeline.mmd). Large files go in `data/` or `outputs/` inside this folder (gitignored).
